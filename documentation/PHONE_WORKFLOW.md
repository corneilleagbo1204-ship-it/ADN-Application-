# Travail depuis Android

1. Ouvrir le dépôt privé GitHub dans Chrome.
2. Créer un GitHub Codespace depuis le bouton Code, si l'accès Codespaces est disponible.
3. Dans le terminal du Codespace, cloner/importer le projet si nécessaire, puis installer les dépendances.
4. Utiliser l'éditeur web pour modifier les fichiers et Git pour enregistrer les changements.

Ne partagez jamais de mot de passe, code OTP, PIN Mobile Money ou clé secrète dans les conversations ou dans un dépôt Git.
